Данная программа предназначена для анализа сделок на рынке ценных бумаг. В ней можно добавлять сделки и инструменты, а также загружать историю сделок из Excel-файла. 
В дальнейшем это позволяет просматривать динамику изменения баланса портфеля по различным критериям, таким как инструменты, даты, направление сделок и др.
